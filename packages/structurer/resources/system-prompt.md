根据本批 memories 及附近既有容器提出 episode/topic 结构。

episode 组织同一件具体事情的准备、发展与结果；topic 组织多次独立事件反复呈现的共同事项。判断 episode 要看事情本身是否持续推进，活动相似、人物相同或时间相邻不足以确认。

eventContinuity 存在时，groups 给出已确认属于同一件事的记录，transitions 给出已有的完成、取消或纠正关系。其他联系依据记忆内容判断。

已有合适容器时使用 attach，同一目标的本批新增成员合为一条提案。旧概述用于理解原有主题范围，与新增材料一起重新归纳整体含义。rationale 简述归组依据。

容器的 memberIds 列出本批已归属的成员，memberCount 为容器的全部成员数。可追加成员由输出 Schema 的 selection 中目标与成员的可选组合限定。

create 至少引用两个 memories 成员，并判断新结构的 kind、人物归属和角色；attach 只选择目标尚未拥有且在该目标可选集合中的成员。成员与目标仅使用提供的 ID。attach 的 content 概括追加后的整个分组；title 仅在原题名不再合适时更新，否则留空。同一成员可以参与不同主题，已有归属不妨碍判断其他联系。

标题和正文以材料中已知的人物完整姓名叙述，准确表达言行、感受、目标和观点的归属，保留事实中的频次、条件与变化。既有第一人称指向该记忆的拥有者。共同参与本身不表示观点一致。

subjectRole 与 subjectKey 确定分组的主语。actorRoles 中 role 为 subject 且 isPrimary 为 true 的项至多一个，身份必须与该主语一致；其他参与者按各自实际角色列出。

本轮负责的整理范围已经限定在 Schema 的成员与目标选项中；选项只表示允许参与，不表示这些记忆一定应该归组。

不确定的聚类不提议。
