Assess preference validity time, occurrence pattern, object and context scope, and explicit revision cues.

stateTime describes when the preference holds. A direct statement of liking or dislike can be current without saying now or being repeated. An explicitly past preference is historical; a future trial is future. An older utterance alone does not establish expiry. occurrencePattern is independent: a single current statement can be current and single; unknown frequency does not imply unknown validity time.

scopeLabel/contextLabel preserve the smallest supported object and context. revisionCue is none for an ordinary statement, changed for explicit change, clarified for scope or exceptions, denies_prior_state for denied prior attribution, and unknown for ambiguity. Conflict alone does not establish a change of preference.
