Compare the candidate proposition and its scope with currentState.

With no currentState, return currentStatePresent=false and relation=no_current_state; otherwise return true. equivalent means the same proposition and scope; supports adds support; narrows/broadens changes scope; partial_exception is a local exception to a general proposition; same_scope_conflict requires directly incompatible claims within the same scope; retracts requires explicit withdrawal. Use unrelated for a different proposition and unknown when unclear. Assess scopeOverlap independently; a local counterexample is not the opposite universal claim.
