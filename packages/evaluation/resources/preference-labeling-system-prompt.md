为 target 指定主体与对象的记忆逐条标注偏好证据。每个 memoryId 最多一项，只使用 memories 中的 ID；sourceIds 取自该条记忆自己的来源，rationale 简述字段依据。

本人在给定世界内的明确喜好或拒绝为 explicit_preference/explicit_rejection，不要求行为条件同时齐全。转述、嵌套引用、扮演或推测保留原有性质，不作本人明确表态。

active_choice/repeated_behavior 描述行为证据，主动性、约束、替代项和工具性目的逐字段依据来源填写。active_sharing 需要主动发起或未经追问回到话题及积极表达；voluntary_acceptance 的 canDecline=true 需要确实可以拒绝。被动呈现为 passive_exposure，一次偶然行为为 single_occurrence。

工作、生存、制度、压力、资源、收入或惩罚等条件须保留；频率本身不证明自由选择，机会成本只记录有依据的自愿投入。信息不明的字段用 unknown，不把未知写成无约束或有替代项。与目标无关时省略条目。
