# 时间召回

日期统一使用 `MemoryService` 的 `defaults.retrieval.timeZone`，默认 `Asia/Shanghai`。同一配置用于抽取输入、片段日期合并、结构候选、偏好证据日期与召回。数据库保留原始时间戳；已有的 `YYYY-MM-DD` 日历日期保持其字面含义。

## 时间解析

`resolveTemporalQuery(query, now, timeZone)` 返回 `matched`、`expression`、`remainingQuery`、`precision`、`coreWindow`、`toleranceWindow` 与 `ordering`。窗口包含 `startDate`、`endDate`，边界均为本地日期且包含端点。顶层 `startDate`、`endDate` 对应核心窗口；无窗口时为 `null`。

| precision | 含义 | 召回方式 |
| --- | --- | --- |
| `exact` | 明确日期或确定的日历区间 | 有话题时正常召回，范围内固定加分 |
| `approximate` | 有具体数字的相对时间，如“两周前”“2 weeks ago” | 话题召回后按窗口加权 |
| `vague` | 模糊时间或次序，如“最近”“前几天”“上次” | 按窗口加权、覆盖历史或选择最新匹配 |

未识别时 `matched: false`，`precision: null`。无年份的月日选择不晚于查询当天的最近一次有效日期；明确年份及“今年”“明年”等限定保留其含义。无年份的季节按最近一次起始日期确定，冬季跨到次年二月。

支持周一至周日的“上周／这周／本周／上上周”，日历月份“上个月／这个月／上上个月”，年份“去年／今年／前年”及“去年十二月”，四季，以及中文数字、阿拉伯数字、“两”“几”“十几”的相对天、周、月、年。

“星期”“礼拜”与“周”等价，支持“两个星期前”。“半个月前”按约十五天前、“半年前”按约六个月前计算，精度为 `approximate`。“上半年／下半年”分别为一至六月、七至十二月；没有年份时选择最近一次已经开始的区间，明确年份时保留限定。“年底／年末”为模糊区间，核心窗口取十一至十二月，容忍窗口取十至十二月，年份采用相同规则。

## 排序窗口

以下以查询当天为第 0 天，负数表示之前的日期：

| 表达 | 核心窗口 | 容忍窗口 |
| --- | --- | --- |
| 这几天、这两天 | -3 至 0 天 | -5 至 0 天 |
| 前几天、几天前 | -6 至 -2 天 | -10 至 -1 天 |
| 前些天 | -6 至 -2 天 | -10 至 -1 天 |
| 前段时间、前阵子 | -42 至 -7 天 | -90 至 -1 天 |
| 最近、近来 | -14 至 0 天，越新时间分越高 | -30 至 0 天 |
| N 天前 | 目标日期前后 1 天 | 前后 3 天 |
| N 周前 | 目标日期前后 3 天 | 前后 7 天 |
| N 个月前 | 目标日期前后 15 天 | 前后 31 天 |
| N 年前 | 目标日期前后 45 天 | 前后 90 天 |
| 几周前、前几周 | -42 至 -14 天 | -60 至 -7 天 |
| 几个月前 | 2 至 6 个月前 | 1 至 9 个月前 |
| 几年前 | 2 至 6 年前 | 1 至 9 年前 |
| 十几天／周／月／年前 | 11 至 19 个单位前 | 10 至 22 个单位前 |
| 二十几天／周／月／年前 | 21 至 29 个单位前 | 20 至 32 个单位前 |
| 以前、之前、很久以前 | 不限时间 | 不限时间 |
| 上次、上一次、last time | 按话题匹配，选择最新一条 | 不使用窗口 |

月份与年份偏移使用本地日历，月底超过目标月天数时取该月最后一天；相对时间的右边界不超过当天。

有话题时，去掉时间表达后照常执行词法、BM25、实体与可用的向量检索。时间不能单独使一条记忆入选。核心窗口时间分为 1，容忍边缘线性降至 0；“最近”核心窗口内的分数从 0.5 随日期增加到 1。窗口外时间分为 0，保留话题得分。

模糊及近似时间的最终分数为 `话题分 × (1 + temporalWeight × 时间分)`。明确日期的最终分数为 `话题分 + temporalWeight × 时间分`，范围内时间分为 1，范围外为 0。有话题时所有时间精度均保留普通检索的匹配，日期不符或缺失不会剔除相关记忆。`temporalWeight` 默认 `0.35`，可通过服务检索配置或单次检索选项设置。候选返回的 `temporalRanking` 包含实际日期、话题分、时间分及权重，便于核对排序。

没有话题时，如“最近我们聊了什么”，在容忍窗口内按日期倒序及重要度返回记忆，受现有候选数和上下文预算限制。只有日期的查询按对应日期或日历区间浏览事件与原话。窗口内为空时返回无匹配；有话题时仍能返回窗口外的话题匹配。“上次”选择不晚于查询当天的最新匹配记忆。

没有话题的“以前／之前／很久以前”不设置日期截止点，而是覆盖不同历史时期：先取重要度最高的记忆，同重要度取较早者，再依次选择与已选日期距离最大的记忆，优先填满现有候选与上下文名额。这样密集的新对话不会占满所有位置。有话题时仍按话题相关性召回，不使用历史覆盖排序。

事件比较 `event_date`，缺失时比较 `event_start` 的本地日期；状态比较 `known_at`，缺失时使用 `valid_from`；原话比较发言时间的本地日期。上下文保留实际日期，状态记录日期与状态生效时间分别说明。
